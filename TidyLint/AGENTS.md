# TidyLint for AI agents

This folder is the TidyLint skill. It cleans up the code of a project with no change in behavior.

- To use the skill, read `SKILL.md` and follow it. It is written for any agent that can read files and run commands.
- `dev/` exists only in the maintainer's copy. Do not read `dev/` when you use the skill. Read it only when the user
  asks you to work on the skill itself.
- When you work on the skill itself, read `dev/STATE.md` and `dev/DECISIONS.md` first, and update them at the end.
  Write the lessons from a test run in general words: no project names, paths, file names or numbers from it.
