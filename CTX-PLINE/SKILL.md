---
name: ctx-pline
description: >-
  Persistent, token-lean project context memory across sessions, models and harnesses. Use it at the start of a
  session to load project decisions, facts, tasks and issues (`load --slim`); before a task to recall the items that
  apply (`recall`); during work to search or inspect items (`find`, `show`, `status`); before the end of a session
  or milestone to save tagged progress (`next`, `save`); or to set up context memory in a project (`init`).
---

# CTX-PLINE

Read [README.md](README.md) in this folder. It holds every rule and command. The `workflow/` folder has one file
of detail per step, and `hooks/` has the setup for each harness.
