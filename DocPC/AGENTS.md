# DocPC for AI agents

This folder is the DocPC skill (Document Pipeline Compose). It builds assignment documents from source files.

- To use the skill, read `SKILL.md` and follow it. It is written for any agent that can read files and run commands.
- If `local/setup.md` does not exist, follow `SETUP.md` first. It is the first-run setup (clean slate or university).
- `dev/` exists only in the maintainer's copy. Do not read `dev/` when you use the skill. Read it only when the user
  asks you to work on the skill itself.
- When you work on the skill itself, read `dev/STATE.md`, `dev/DECISIONS.md`, `dev/HISTORY.md` and `dev/CONVERSATION.md` first.
  At the end, update them: add the new requests of the user to `CONVERSATION.md` as a new part.
- To commit or push the skill to GitHub, follow `dev/PUBLISH.md`.
